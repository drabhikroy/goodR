goodR now runs on Linux and Windows as well as the Mac. The Linux and Windows versions are a preview: they are built and tested by machine, and are waiting on reports from people using them on a real desktop. If you already have goodR on a Mac, install this version over it. Your settings, projects, and scripts stay as they are.

## New

- **Linux (preview).** A Debian package for Ubuntu, Debian, and other systems that use `.deb` files, and an AppImage for any other distribution. Installing the Debian package teaches the system what R scripts, R Markdown, and Quarto documents are, so goodR is offered when you open one from your file manager.
- **Windows (preview).** An installer for Windows 10 and 11 that installs for your account alone, with no administrator password. The installer is not yet code signed, so Windows shows "Windows protected your PC" the first time it is opened. Choose More info, then Run anyway.
- On both, a script opened while goodR is running opens as a tab in the window you already have, and the keyboard shortcuts use Ctrl where a Mac uses Command.

## Good to know on Linux and Windows

- goodR uses the R already on your computer, as on a Mac. It needs R 4.2 or later. On Ubuntu 22.04 the system's own R is older than that, so install R from CRAN's repository instead.
- The assistant works with the Ollama you install from ollama.com. Only the Mac version can install a private copy of Ollama for you.
- Updates are offered through the release page, not installed from inside the app.

## Changed

- The assistant's setup and the opening screen name the computer and its file manager the way each system does, such as this computer and File Explorer on Windows.
- The first example script gives the run shortcut for every system.

## Install

Every installer and its checksum file are listed below. The [README](https://github.com/drabhikroy/goodR#install) has the steps for each system, and how to check a download.

- **Mac:** `goodR-1.1.0.pkg`, with `SHA256SUMS.txt`
- **Linux, Intel or AMD:** `goodR-1.1.0-amd64.deb` or `goodR-1.1.0-x86_64.AppImage`, with `SHA256SUMS-linux-x64.txt`
- **Linux, ARM:** `goodR-1.1.0-arm64.deb` or `goodR-1.1.0-aarch64.AppImage`, with `SHA256SUMS-linux-arm64.txt`
- **Windows:** `goodR-1.1.0-x64-setup.exe`, with `SHA256SUMS-windows.txt`

The Mac installer is signed and notarized by Apple, so it opens without a security warning.

## Feedback

This is the first release on Linux and Windows, so reports from those systems are especially welcome, whether something works or not. Please [open an issue](https://github.com/drabhikroy/goodR/issues) and say which system and version you are on.
