This update fixes problems found since 1.0.0. If you already have goodR, install this version over it. Your settings, projects, and scripts stay as they are.

## Fixed

- Open Posit Community and Open Stack Overflow, in Ask for help online, now open the forum. Before, they only said the browser did not open.
- A chunk whose options include a brace, such as a LaTeX `\label{}` in a figure caption, now runs. Before, its code was skipped without any message.
- When a report fails, it again names the line that failed and underlines it in your script. With recent versions of knitr, it showed only R's message.
- A chunk that names another language with `engine =`, such as C++, is no longer sent to R.
- In older R Markdown documents where a chunk ends at the next chunk's header, that header is no longer sent to R as code.
- A page break, or a wide space on a line of its own, no longer counts as a statement when you run a line.
- If goodR closes unexpectedly while a Shiny app is running, the app's R now stops within a few seconds instead of running on in the background.
- The App pane now shows only the app you ran, even when the app prints the address of some other program on your Mac.
- The preview of an app shared as a web page now answers only at its own address, so a web page elsewhere cannot read it.
- If the settings file is damaged more than once, each damaged copy is kept under a name of its own instead of replacing the last one.
- The opening screen now counts the examples correctly: eight scripts and documents, and four Shiny apps.

## Privacy

The [privacy page](https://github.com/drabhikroy/goodR/blob/main/docs/PRIVACY.md) now also describes two things the app has always kept on your Mac: earlier versions of each script you save, and your latest results, so they come back next time. It says where they are and how to clear them.

## Install

1. Download `goodR-1.0.1.pkg` below.
2. Open it and follow the steps. macOS asks for an administrator password because the installer puts the app in your Applications folder.
3. Open goodR from the Applications folder.

The installer is signed and notarized by Apple, so it opens without a security warning.

If you want to confirm the download is intact, put `goodR-1.0.1.pkg` and `SHA256SUMS.txt` in the same folder, open Terminal in that folder, and run `shasum -a 256 -c SHA256SUMS.txt`. It should answer `goodR-1.0.1.pkg: OK`.
