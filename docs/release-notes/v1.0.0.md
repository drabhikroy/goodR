R: What Is It Good For? is an integrated development environment for writing and programming in R.

Similar to other IDEs your code is on one side of the window and your results are on the other. Run a line and its chart or table appears beside it. Click a result later and you are taken back to the line that made it. When something goes wrong, the app explains the problem in plain words and marks where it happened, instead of leaving you with R's error message alone.

From there, the same window takes you through a whole piece of work: exploring a data set, running an analysis, writing it up as a report, and building a Shiny app. There is a short tour, a set of examples to try, and a guided first project if you are just starting out. The [README](https://github.com/drabhikroy/goodR#readme) has an introduction, and the [feature guide](https://github.com/drabhikroy/goodR/blob/main/docs/FEATURES.md) covers everything in detail.

## What it does

- Runs a line, a section, or a whole script and shows each result beside the code that made it
- Keeps earlier results in a strip so you can go back to them or pin one to compare
- Explains errors and warnings in plain words and offers a fix for common problems such as a missing package
- Finds code that packages have retired and updates it in one step
- Writes up a question for a forum with the code, a small data sample, and your versions
- Shows data column by column and writes your filters and renames into the script as R
- Renders R Markdown and Quarto documents to HTML, Word, and PDF beside the code
- Runs Shiny apps beside their code, maps how their parts connect, and flags likely mistakes before they run
- Gives each project its own R so work in one never leaks into another
- Undoes the last run, recovers unsaved work after a crash, and keeps earlier versions of every script
- Writes up tests and models in APA style and checks their assumptions
- Traces any object back through the lines that made it
- Turns a script into exercises that check each answer
- Includes an optional assistant that runs on your own computer through Ollama
- Offers light, dark, and paper themes, palettes for color vision, and sixteen code fonts
- Lists updates for the app, R, your packages, Ollama, and assistant models on one page

## Before you install

You need a Mac with macOS 12 Monterey or later, on Apple silicon or Intel.

You also need R 4.2 or later. The app uses the R on your Mac, so if you have not installed R yet, download it from [CRAN](https://cran.r-project.org/bin/macosx/) first. Pick arm64 for an Apple silicon Mac or x86_64 for an Intel Mac.

## Install

1. Download `goodR-1.0.0.pkg` below.
2. Open it and follow the steps. macOS asks for an administrator password because the installer puts the app in your Applications folder.
3. Open goodR from the Applications folder. It finds R on your Mac and starts it.

The installer is signed and notarized by Apple, so it opens without a security warning.

If you want to confirm the download is intact, put `goodR-1.0.0.pkg` and `SHA256SUMS.txt` in the same folder, open Terminal in that folder, and run `shasum -a 256 -c SHA256SUMS.txt`. It should answer `goodR-1.0.0.pkg: OK`.

## Privacy

Your code and data stay on your Mac. The app never collects usage data nor does it send crash reports. It only goes online to check for updates. You can set it to check only when you ask.
