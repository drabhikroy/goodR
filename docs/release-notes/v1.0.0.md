R: What Is It Good For? is a desktop app for writing R on a Mac. You write your script on the left. When you run a line, its plot, table, or printed result shows up on the right, and you can click the result to get back to the line that made it.

This is the first public release.

## What you can do with it

Run R a line, a section, or a whole file at a time. Older results stay in a strip under the newest one, so you can go back to a plot from an hour ago, or pin one to compare it with what comes next.

When something goes wrong, the app says what happened in plain words and marks the line. If the fix is obvious, such as installing a missing package or updating code that a package has retired, there is a button that does it. Warnings and failed package installs get the same treatment.

The data viewer shows each column with its type, a small chart, and how many values are missing. If you filter or rename something there, the app writes that change into your script as a line of R, so your analysis still runs from start to finish without the viewer.

R Markdown and Quarto documents render in the window, and can render again each time you save. Shiny apps run beside their code. The app also draws a map of how the app's inputs and outputs connect, and points out likely mistakes, such as an output name that does not match the UI, before you run it.

Other things that are there when you need them:

- Each project gets its own R, so objects from one never turn up in another.
- You can undo the last run, and unsaved work comes back after a crash.
- Every script keeps earlier versions, and you can see what changed.
- Statistical results can be written up in APA style, with the assumptions checked.
- You can trace any object back through the script to see where it came from.
- Teachers can turn a script into exercises that check students' answers.
- There is an optional assistant that runs on your own Mac through Ollama.
- Light, dark, and paper themes, palettes for color vision differences, and sixteen code fonts.

Updates for the app, R, your packages, Ollama, and assistant models are all listed on one page in Settings.

The full list, with screenshots, is in [the feature guide](https://github.com/drabhikroy/goodR/blob/main/docs/FEATURES.md).

## What you need

- A Mac with macOS 12 Monterey or later. Apple Silicon and Intel both work.
- R 4.2 or later. You can get it from [CRAN](https://cran.r-project.org/bin/macosx/).

That is enough to write and run R. For reports and Shiny apps you will need a few R packages, and Quarto if you use Quarto documents. The app tells you what is missing the first time you need it, and installs R packages for you if you say yes.

## Installing

1. Download goodR.dmg from the files below. The same file works on Apple Silicon and Intel Macs.
2. Open it and drag goodR into Applications.
3. Open goodR from Applications.

The app is signed with a Developer ID and notarized by Apple, so macOS opens it without a warning. If you want to check that your download is intact, put goodR.dmg and goodR.dmg.sha256 in the same folder and run this in Terminal:

```bash
shasum -a 256 -c goodR.dmg.sha256
```

It should print `goodR.dmg: OK`.

## Privacy

The app does not collect usage data or send crash reports. Your code and data stay on your Mac. On its own, the app only checks for updates, which means asking GitHub, CRAN, and Ollama for their latest version numbers. You can turn that off in Settings so it only checks when you ask.

## Not in this release

It only runs on macOS for now. Windows and Linux versions are planned. R is not bundled, so you need to install it yourself; if the app cannot find R, it points you to CRAN.
