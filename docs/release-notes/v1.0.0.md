R: What Is It Good For? is a Mac app for writing and running R, and this is its first public release.

The idea is simple. Your code is on one side of the window and your results are on the other, and the two stay connected. Run a line and its chart or table appears beside it. Click a result later and you are taken back to the line that made it. When something goes wrong, the app explains the problem in plain words and marks where it happened, instead of leaving you with R's error message alone.

From there, the same window takes you through a whole piece of work: exploring a data set, running an analysis, writing it up as a report, and building a Shiny app. There is a short tour, a set of examples to try, and a guided first project if you are just starting out. The [README](https://github.com/drabhikroy/goodR#readme) has an introduction, and the [feature guide](https://github.com/drabhikroy/goodR/blob/main/docs/FEATURES.md) covers everything in detail.

## Before you install

You need a Mac with macOS 12 Monterey or later, on Apple silicon or Intel.

You also need R 4.2 or later. The app uses the R on your Mac, so if you have not installed R yet, download it from [CRAN](https://cran.r-project.org/bin/macosx/) first. Pick arm64 for an Apple silicon Mac or x86_64 for an Intel Mac.

## Install

1. Download goodR.dmg from the list of files at the bottom of this page.
2. Open it and drag goodR into your Applications folder.
3. Open goodR. It finds R on your Mac and starts it.

The app is signed and notarized by Apple, so it opens without a security warning.

## Good to know

Your code and data stay on your Mac. The app collects no usage data, sends no crash reports, and only goes online to check for updates.

This release runs on macOS only. Windows and Linux versions are planned.

If you want to confirm the download is intact, put goodR.dmg and goodR.dmg.sha256 in the same folder, open Terminal in that folder, and run `shasum -a 256 -c goodR.dmg.sha256`. It should answer `goodR.dmg: OK`.
