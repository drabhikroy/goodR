goodR, or R: What Is It Good For?, is a desktop app for writing R on a Mac. Your script is on the left, and every plot, table, and printed result lands on a canvas on the right, linked to the line that made it. It is meant for people new to R and for people who use it every day.

This is the first public release.

## Overview

- **Script on the left, results on the right.** Each result links back to its line, and earlier results stay in a strip under the canvas to revisit or pin side by side.
- **Errors in plain English.** The failing spot is marked in the script, with a one click fix when the fix is clear. Warnings and failed package installs are explained the same way.
- **Data you can see.** The data viewer summarizes every column, and each change made there, such as keeping some rows, is written into your script as a line of R.
- **Reports and apps beside the code.** R Markdown and Quarto documents render in the window and again each time you save. Shiny apps run beside their code, with a map of how their inputs, reactives, and outputs connect, and likely mistakes are found before the app runs.
- **An R for each project,** so work in one never leaks into another.
- **Safety nets.** Undo the last run, unsaved work that survives a crash, and earlier versions of every script with what changed since.
- **For research and teaching.** Statistics written up in APA style with their assumptions checked, Where did this come from? to trace an object back through a script, and exercises made from a script that check themselves.
- **An optional assistant** that runs on your own Mac through Ollama. Nothing you write is sent anywhere.
- **Made to be read.** Light, dark, and paper themes, color vision palettes, sixteen code fonts, a layout you can trim, and screens checked against WCAG 2.2 AA.
- **Updates in one place** for the app, R, packages, Ollama, and assistant models.

The full list is in [FEATURES.md](https://github.com/drabhikroy/goodR/blob/main/docs/FEATURES.md).

## Requirements

- macOS 12 Monterey or later, on Apple Silicon or Intel
- R 4.2 or later, from [CRAN](https://cran.r-project.org/bin/macosx/)

The R kernel, ark, ships inside the app, so nothing else is needed to write and run R. Rendering reports and running Shiny apps need a few R packages and, for Quarto documents, [Quarto](https://quarto.org/docs/get-started/). The app says what is missing and installs R packages with one press.

## Install

1. Download **goodR.dmg** below. One disk image runs on both Apple Silicon and Intel Macs.
2. Open it and drag goodR to **Applications**.
3. Open goodR from **Applications**.

The app is signed with a Developer ID and notarized by Apple, so it opens without a warning. To check the download against the published checksum, put both files in the same folder and run:

```bash
shasum -a 256 -c goodR.dmg.sha256
```

## Privacy

goodR collects no usage data and sends no crash reports. R runs on your Mac. The only requests it makes on its own are the update checks, which ask GitHub, CRAN, and Ollama for their newest version numbers. Settings can limit them to when you ask.

## Known limits

- Mac only for now. Windows and Linux are planned.
- R itself is not included. The app finds the R you have and points you to CRAN when there is none.
