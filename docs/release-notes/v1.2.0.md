This release gives History a new look, makes Show me walk through the window one part at a time, and makes running a Shiny app work the way it does in RStudio. If you already have goodR, install this version over it. Your settings, projects, scripts, and saved versions stay as they are.

## New

- **Shiny apps run in a window of their own.** A running app opens in its own window, with its address, Open in browser, and Reload along the top. Closing the window stops the app, along with every background worker it started, such as one made with callr. Links in the app to other sites open in your browser, and a file the app offers goes to your Downloads folder. The App sheet beside the code still explains errors inside the app and maps how it connects.
- **Likely mistakes in an app are checked against the whole app.** goodR now reads every file of an app, including helpers in the R folder and the page's JavaScript, before it calls something a mistake. On nine real apps that run fine, the earlier check reported 390 mistakes. The new one reports none, and still finds the typos and reactives left without parentheses that were planted in them to test it. The list starts folded to one line, Hide puts it away until a new kind of mistake appears, and a setting under Results turns the check off. R Markdown documents that run Shiny have their code chunks checked.
- **Projects open from Finder.** An `.Rproj` file opened with Open With, dropped on the window, or named on the command line opens its project, as RStudio does. goodR offers itself for R projects without taking over from RStudio.
- **Show me walks through each Help topic.** The window dims, an iris closes on each part in turn, a gold ring draws itself around it, a pointer glides there and presses it where it is a button, and a card says what the part does, with Back and Next.
- **Help is one press away.** A question mark sits at the foot of the tools, above Home.

## History

- Every save you make is kept, however soon after the last, and so is every run that works. Only autosave folds together, one version for each five minutes. Up to two hundred versions are kept for each script.
- History opens at the full size of the window. It shows the script then and now, side by side, with the changes named for their section.
- Earlier versions are a deck of cards you flip back through with the slider, the arrow keys, or a click on a card behind. Under the slider, saves made in the same minute share one time, and each version has its own dot, with a cross for one where a line did not run.
- When a line fails that worked before, its result shows how it last worked beside how it is now, with one press to put it back.

## Changed

- The workspace is calmer: the tools run down the right edge, earlier results are stepped through on the stage, and the files, R's status, and Close project are in the project menu. The project menu shows the project's lettered tile, so which project is open shows even with the sidebar closed.
- The bar above the script now fits whatever width its column has, and drops words before pictures, so the buttons never end up under the Results pane. The open script's tab stays in view.
- Update all installs a newer copy of each package where R loads it from, or into your own library when that folder cannot be written to, and checks again afterward. Packages that are out only as source code are named apart, since they cannot be installed ready-built yet.
- A tool's name shows a moment after the pointer rests on it. A right-click on the tools, or View, Show or Hide Names Under the Tools, writes every name under a larger icon.
- The Run button's choice for scripts and documents is kept between launches.
- A report whose file has changed since it was rendered, even while the file was closed, is marked as out of date instead of shown as current. An R Markdown document renders the way its own `knit` line says.

## Removed

- The option to show a running app inside the App sheet, and its setting. The window that holds the app on a Mac and on Linux blocks a plain web page inside another page without saying so, so the sheet showed nothing. The app's own window does the same job.

## Install

Every installer and its checksum file are listed below. The [README](https://github.com/drabhikroy/goodR#install) has the steps for each system, and how to check a download.

- **Mac:** `goodR-1.2.0.pkg`, with `SHA256SUMS.txt`
- **Linux, Intel or AMD:** `goodR-1.2.0-amd64.deb` or `goodR-1.2.0-x86_64.AppImage`, with `SHA256SUMS-linux-x64.txt`
- **Linux, ARM:** `goodR-1.2.0-arm64.deb` or `goodR-1.2.0-aarch64.AppImage`, with `SHA256SUMS-linux-arm64.txt`
- **Windows:** `goodR-1.2.0-x64-setup.exe`, with `SHA256SUMS-windows.txt`

The Mac installer is signed and notarized by Apple, so it opens without a security warning. The Linux and Windows versions are still a preview, and reports from them are welcome. Please [open an issue](https://github.com/drabhikroy/goodR/issues) and say which system and version you are on.
