This update fixes two behaviors found after 1.0.1 and makes the private assistant safer. If you already have goodR, install this version over it. Your settings, projects, and scripts stay as they are.

## Changed

- Running a whole document, or everything up to the cursor, now leaves out a chunk you switched off with `eval=FALSE` (or `#| eval: false` in Quarto), as rendering does. Before, those chunks ran, including ones that install packages. Run chunk on that chunk still runs it, since you asked for it.

## Fixed

- The private copy of Ollama now stops by itself within a few seconds if goodR closes unexpectedly, so a model is not left in your Mac's memory. Before, it stopped only when goodR quit normally.
- The features page no longer implies that a misspelled function name gets a suggested correction. Misspelled functions are explained, and misspelled objects and columns get the closest name, as before.

## Install

1. Download `goodR-1.0.2.pkg` below.
2. Open it and follow the steps. macOS asks for an administrator password because the installer puts the app in your Applications folder.
3. Open goodR from the Applications folder.

The installer is signed and notarized by Apple, so it opens without a security warning.

If you want to confirm the download is intact, put `goodR-1.0.2.pkg` and `SHA256SUMS.txt` in the same folder, open Terminal in that folder, and run `shasum -a 256 -c SHA256SUMS.txt`. It should answer `goodR-1.0.2.pkg: OK`.
