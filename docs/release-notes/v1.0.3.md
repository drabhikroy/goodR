This update makes the workspace easier to read and a failed script easier to fix. If you already have goodR, install this version over it. Your settings, projects, and scripts stay as they are.

## Changed

- The way Run runs now stays where you put it. Choosing Run file, Run section, or Run line in the Run menu runs it and keeps that choice until you change it by hand. Before, the button went back to Run line after each use. A script and a document each remember their own choice.
- Earlier results are laid out in lanes, one for each section of your script, with a count of results, problems, and lines not run. The strip starts a little taller so a lane fits without scrolling.
- The right panel is quieter. The view tabs are underlined, and show their icons only when the panel is narrow. The title of the result on the stage and its actions share one row. Import data and Clear are small icon buttons. Nothing was removed.
- The menu at the left of the tab strip is now a labeled button with an icon for a project, a script on its own, or a scratch file. A script on its own reads "Single script" there, so its name is no longer shown twice.

## Added

- When a line fails, the explanation lists the names the line was using and what R holds under each one. A name R has nothing under comes first, and so does a column the data frame does not have, since a misspelling is the likely cause.
- Run from line N on, on a failed result, runs that line and everything after it without running the earlier lines again. The same is in the Run menu as Run from Here to the End.
- A count of failed lines, such as "2 problems", appears above the script while a file has any. Go to Next Problem and Go to Previous Problem, F8 and Shift+F8, step between them. On a Mac keyboard that sends media keys first, hold Fn.

## Fixed

- A Shiny app now stops when you close its script, as well as when you press Stop. For an app split into `ui.R` and `server.R`, closing either one stops it. Before, it kept running until you pressed Stop.
- A Typst PDF no longer fails on its first chunk with no open graphics device on a Mac without XQuartz. goodR now asks for PNG figures when it makes a Typst PDF, unless your document sets its own figure format.

## Install

1. Download `goodR-1.0.3.pkg` below.
2. Open it and follow the steps. macOS asks for an administrator password because the installer puts the app in your Applications folder.
3. Open goodR from the Applications folder.

The installer is signed and notarized by Apple, so it opens without a security warning.

If you want to confirm the download is intact, put `goodR-1.0.3.pkg` and `SHA256SUMS.txt` in the same folder, open Terminal in that folder, and run `shasum -a 256 -c SHA256SUMS.txt`. It should answer `goodR-1.0.3.pkg: OK`.
